# Домашнее задание №1 — развёртывание HDFS-кластера

Цель работы — развернуть отказоустойчивое распределённое хранилище на базе
Apache Hadoop HDFS 3.4.1 для команды `team-24`.

В рамках задания настроен кластер из четырёх виртуальных машин:

- edge-нода с HDFS-клиентом;
- NameNode и Secondary NameNode;
- три DataNode с коэффициентом репликации 3.

Развёртывание автоматизировано набором Bash-скриптов. Они устанавливают Java 11
и Hadoop, настраивают узлы и сетевые имена, создают службы `systemd`, запускают
компоненты в правильном порядке и поддерживают безопасный повторный запуск.

Добавлена автоматическая проверка состояния кластера: доступность всех служб,
регистрация трёх DataNode, отсутствие повреждённых блоков, запись и чтение
тестового файла, наличие трёх реплик и проверка контрольной суммы.
